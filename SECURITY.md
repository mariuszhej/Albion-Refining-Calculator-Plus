# Security Policy

## Supported Versions

Only the latest version of Albion Refining Calculator receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue
2. Send an email to: mariuszhej@users.noreply.github.com
3. Create a security advisory on GitHub: https://github.com/mariuszhej/Albion-Refining-Calculator-Plus/security/advisories/new
3. Include:
   - Vulnerability description
   - Steps to reproduce
   - Potential impact
   - Suggested fix (optional)

### Response Timeline

- **Initial response**: Within 48 hours
- **Detailed assessment**: Within 7 days
- **Fix release**: Based on severity
  - Critical: 72 hours
  - High: 7 days
  - Medium: 14 days
  - Low: 30 days

## Security Best Practices

This application follows these security practices:

- ✅ No server-side data collection
- ✅ No authentication required
- ✅ Local storage only for settings
- ✅ HTTPS enforced for API calls
- ✅ No third-party tracking scripts
- ✅ Input validation and sanitization
- ✅ CSP headers implementation

## What We Protect

- User settings and preferences
- API communication
- Price data integrity
- User privacy

## What We Don't Collect

- Personal information
- Usage analytics
- IP addresses
- Game credentials
